# Contribution and review workflow

Use your own student GitHub account and an identifiable commit author. Do not share accounts, manufacture earlier timestamps, assign work to another student without confirmation, or treat initial preparation as evidence of their independent contribution.

1. Create a real YouTrack task with an assignee, priority, deadline, outcome and testable acceptance criteria.
2. Branch from the accepted baseline using the issued task ID, for example `GEMZ-23-profile-export`. This example is not an existing task.
3. Commit coherent changes with that task ID; include documentation and tests appropriate to the change.
4. Open a PR explaining behavior, requirement/task links, checks and limitations. Link the PR back in YouTrack.
5. Another team member reviews before merge. Record substantive feedback and resulting revisions; do not invent review comments.
6. Mark the task complete only after its actual acceptance criteria pass. Tag a submission only after the agreed review.
